Catalogue and standards

The whole collection is described by a static STAC 1.0 catalogue, readable by QGIS (STAC plugin), pystac, rstac and any STAC browser. Grids are CF-1.8 NetCDF (int16 packed, zlib), on WGS 84 (EPSG:4326) at 0.1°; rasters are GeoTIFF. Tables are UTF-8 CSV with ISO 8601 dates. Page metadata follows schema.org DataCatalog so search engines index it.

Reading the files

import xarray as xr
ds = xr.open_dataset("no2_monthly.nc")          # decoded to µmol m-2
ds.no2.sel(time="2024-11").plot()

In QGIS: Layer → Add Raster Layer → the NetCDF; each band is one month.
